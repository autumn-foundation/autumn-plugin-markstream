# CLAUDE.md

Autumn plugin for markstream (streaming Markdown). Rust crate, Autumn 0.8.

## Layout

- `src/assets.rs`: the `PluginAssets` bundle.
- `src/vendored.rs`: generated by `scripts/vendor.py`. Do not edit.
- `src/plugin.rs`: `MarkstreamPlugin`.
- `src/script.rs`: head tags.
- `src/markstream.rs`: the `Markstream` builder and attribute names.
- `src/sse.rs`: SSE protocol and helpers.
- `assets/core.js`: pure JS helpers (node tests). `assets/init.js`: DOM glue.
- `assets/vendor/`: vendored upstream files. Do not edit by hand.

## Rules

- Keep attribute names and values the same in `src/markstream.rs` and
  `assets/core.js`. A test checks this.
- Keep event names the same in `src/sse.rs` and `assets/core.js`.
- Write no inline script and no import map. The default CSP blocks them.
- Default to safe values (`escape` HTML policy).
- Write docs and comments in ASD-STE100 style: short, active, simple tense.

## Commands

```sh
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
node --test tests/js/*.test.mjs
cargo build --example markstream_demo && node tests/e2e/demo.e2e.mjs
cargo llvm-cov --lib --fail-under-lines 85
python3 scripts/vendor.py   # update vendored files
```

The e2e test needs the `playwright` package and Chromium.

Pre-commit hook: `git config core.hooksPath .githooks`.
